# Site do Kaizen

Página de divulgação do [Kaizen](https://github.com/Cabrly/kaizen). HTML, CSS e JS puros, sem build.

Pra ver no PC: `python -m http.server 8020` nesta pasta e abra http://localhost:8020
(precisa de servidor por causa do `pix.js`, que é módulo).

- **Pix:** edite os `data-pix-*` da seção `#apoie` no `index.html`.
- **Downloads:** os links pegam sozinhos os arquivos da última versão no GitHub.
- **Prints:** ficam em `img/telas` e `img/cenas`, tirados de uma cópia do app com tarefas fictícias.
